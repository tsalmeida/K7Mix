# Jewel-case insert

The cassette **sticker** (the paper label on the shell) is not the jewel-case **insert** (the J-card that slides into the Norelco box).

## Shared measurements

| Piece | Size |
| --- | --- |
| Cassette shell (IEC 60094-1) | 100.4 × 63.8 × 12 mm |
| Jewel case (Norelco) | 109.5 × 69.8 × 16.5 mm |
| Artwork crop | 100.4 / 63.8 ≈ 1.573:1, the cassette face |
| J-card front | 100 × 64 mm |
| J-card spine | 12.5 × 64 mm |
| J-card back | 70 × 64 mm |
| Top / bottom flaps | 10 mm |
| Bleed | 3 mm |
| Safe area | 3 mm inside folds and trim |
| Cassette labels | 89 × 43 mm, side A and side B |

The Typst PDF is exported at actual size with crop marks. Print at 100 %, no "fit to page". Saved artwork crops are reused; without artwork the insert uses the tape colour, sticker colour, title and font.

Title font identifiers are the same four used on the on-screen cassette and in Running Wild: `cousine`, `roboto`, `rock-salt`, `fixedsys`.
