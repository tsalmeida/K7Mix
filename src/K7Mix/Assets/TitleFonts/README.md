# Cassette title fonts

These four faces are the only title fonts K7 Mix and Running Wild share.

| Id | File | Licence |
| --- | --- | --- |

| `roboto` | Roboto-Regular.ttf | SIL Open Font License 1.1 |
| `rock-salt` | RockSalt-Regular.ttf | Apache License 2.0 |
| `fixedsys` | FSEX302.ttf | CC0 / public domain |

The notices sit beside the files. Roboto is also the UI face (`Assets/Fonts`).
